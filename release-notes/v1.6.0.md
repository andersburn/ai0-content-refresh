Version 1.6.0 makes the saved publishing choice apply consistently to new manual and scheduled runs.

- **Save proposals for review:** open a Pending review entry and click Publish this proposal. There is no later automatic approval.
- **Publish automatically after technical validation:** new manual and scheduled runs publish immediately after validation. Manual buttons say Generate and publish.
- Two separate radio choices explain the behavior and the separate scheduling switch.
- Existing pending entries remain for manual approval; changing the setting does not publish old proposals.
- Stale forms are refused after mode changes. Switching to review during a request retains the proposal.
- Automatic-publication failures retain the proposal and record the reason in history.
- Existing settings, quotas, six-month cooldown, media protection and restore behavior are preserved.

**Setup:** choose the desired option under Settings → When a proposal is ready and save. Enable Scheduled reviews separately for unattended generation.

Validation: 76 regression checks, 107 existing WordPress integration checks, 28 publishing checks and 33 language/update checks. Provider responses were simulated.

### Installation and requirements

- PHP **8.1+** with OpenSSL and mbstring; WordPress **6.7+**.
- Gutenberg is the primary editor; ordinary classic HTML is supported.
- **Not tested with Elementor.**
- Your own OpenAI API key and compatible Responses + Structured Outputs model.
- InnoDB for publishing; working WP-Cron for scheduled reviews.
- English source strings with bundled Danish translation.

Sites already running 1.5.0 can update through WordPress. Otherwise install **ai0-content-refresh-1.6.0.zip** once. Settings, credentials and history are retained. Use the named installation ZIP rather than GitHub's generated source archive.
