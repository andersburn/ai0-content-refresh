The first standalone plugin for AI-assisted improvements to existing WordPress pages and posts.

- Your own OpenAI API key, model selection and editable prompt.
- Monthly scheduling, review or automatic publication, and usage limits.
- Google Search Console OAuth, internal view counter and manual priorities.
- Preserve Gutenberg blocks, media, banners and links; add editable content elements.
- Six-calendar-month cooldown, history, diff, publishing and restore.

### Installation and requirements

- PHP **8.1+** with OpenSSL and mbstring.
- WordPress **6.7+**.
- Primarily Gutenberg / the WordPress block editor; ordinary classic HTML is supported.
- **Not tested with Elementor.**
- Your own OpenAI API key and access to a model with Responses + Structured Outputs.
- InnoDB for publication; WP-Cron for scheduling.

This historical installation ZIP retains its original Danish interface. Use the latest release for English source strings and bundled translations.

Upload **ai0-content-refresh-1.0.0.zip** in WordPress and choose replace when upgrading. GitHub's generated source archive is not the installation package.
