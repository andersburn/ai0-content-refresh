- PHP **8.1+** with OpenSSL and mbstring.
- WordPress **6.7+**.
- Primarily Gutenberg / the WordPress block editor; ordinary classic HTML is supported.
- **Not tested with Elementor.**
- Your own OpenAI API key and access to a model with Responses + Structured Outputs.
- InnoDB for publication; WP-Cron for scheduling.
